# Working glossary

[Course home](README.md)

| Term | Meaning in this course |
| --- | --- |
| Activation | A first meaningful use that helps a buyer experience the product's intended value. |
| Affiliate | A promoter compensated under agreed conditions, often for eligible attributed sales. |
| Attribution | A model for assigning credit to observed interactions before an outcome. It is not automatically causal proof. |
| Audience | People your communication reaches or who choose to follow it; not necessarily buyers. |
| Awareness | What a potential buyer already recognizes about the problem, possible solutions, and your offer. |
| A/B test | A comparison using assignment to variants, ideally randomized for a causal question. |
| CAC | Customer acquisition cost: defined acquisition spend divided by acquired customers. State what costs and customers count. |
| Call to action | A clear invitation to take a specific next step. |
| Campaign | A bounded initiative grouped for planning and measurement. |
| Channel | A route through which people discover or interact with the offer. |
| Cohort | A group sharing a starting event, observed over a defined period. |
| Contribution | Amount remaining after specified variable costs; state whether acquisition and creator time are included. |
| Conversion | A defined desired action, such as a confirmed purchase. |
| Conversion rate | Successful actions divided by a matching set of opportunities in a stated window. |
| Copy | Words that support an appropriate decision or action. |
| CTR | Click-through rate: clicks divided by defined exposures. Repeat exposures and click definitions affect interpretation. |
| Deliverability | The practical ability to reach recipient mail systems and inboxes; not guaranteed by authentication alone. |
| Differentiation | A useful, supportable difference relevant to the buyer's choice. |
| Evergreen | Available continuously rather than only during a real scheduled enrollment period. |
| Funnel | A simplified representation of customer stages, though real journeys can loop. |
| Gross sales | Sales amount before the deductions specified in a financial model; distinguish it from profit and taxes collected. |
| Intent | The task or goal behind a search or other action. |
| Lead magnet | A useful resource offered as part of an explicitly described relationship, often subscription. |
| Lifetime value | Value across a customer's relationship under a defined calculation and period; early forecasts can be highly uncertain. |
| Message match | Continuity between the promise that brings someone to a destination and what they find there. |
| Niche | A focused set of buyer needs and situations chosen for service. |
| Offer | Product, audience, outcome, price, delivery, support, limitations, and terms considered together. |
| Opt-in | A deliberate subscription choice under the described process and applicable requirements. |
| Positioning | How an offer is understood relative to a buyer's situation and alternatives. |
| Product-market fit | A useful but imprecise label for strong alignment between a product and sustained market demand; not established by a few likes. |
| Retention | Continued customer relationship or use; for subscriptions it can include continued payment. |
| ROAS | Attributed ad revenue divided by ad spend; it does not account for every cost. |
| Segmentation | Grouping contacts by relevant, justified context to communicate appropriately. |
| SEO | Helping search systems and people discover and understand relevant public content. |
| Social proof | Evidence from others' actual experience; its authenticity and context matter. |
| UTM | URL parameters used to label external acquisition context in a compatible measurement setup. |
| Value proposition | A clear account of the useful progress an offer supports for a specific buyer. |

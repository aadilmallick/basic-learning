# AI Video Production: Complete Learning Curriculum

This curriculum teaches how to plan, design, build, review, and publish AI-assisted animated video. It combines first-principles visual storytelling and motion design with Remotion, HyperFrames, generative media, audio, editing, and automation. The fifteen numbered files are complete lessons; this README is an index.

Work through the lessons in order if the subjects are new. Each one includes explanations, code or technical examples, and prompts for Claude Code and Codex. Examples marked as fragments require an existing project; provider-specific commands and APIs should be checked against current official documentation before use. The lessons explain where generated imagery is useful and where exact, editable graphics are preferable. They do not require paid tools for every example.

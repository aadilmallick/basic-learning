# Aadil's Comedy Sketch Creator Playbook

Start with **Aadil-Comedy-Sketch-Growth-Playbook.pdf**, the 30-page report. It covers original premise development, characters, solo filming, eyelines, performances, comic timing, TikTok and Shorts marketing, separate metric definitions, a 16-sketch publishing calendar, and a 90-day growth process.

**Aadil-Comedy-Sketch-Growth-Playbook.md** is the editable text edition. Use the extracted package to preserve its relative link to **assets/solo-filming-layout.svg**.

**Sketch-Production-Workbook.md** contains reusable premise, character, shot, edit, platform-log and review forms, plus twelve additional premises to develop. The report includes five complete original practice scripts and alternative endings. These are writing material, not audience-tested guarantees.

The Tra Rags reference study verifies accessible public title/description metadata. Full video playback and transcripts were unavailable, so no shot-by-shot or private-analytics study is claimed. The report separates that limited observation from original teaching recommendations.

**verification.json** records document and arithmetic checks. The PDF was rendered and visually inspected; the metric examples and weekly calendar arithmetic were checked. No live platform account, publishing, editor, audience test, sponsorship or income result was operated or produced.

Suggested working metrics are experiments, not official thresholds. Start with a repeatable comic point of view and a manageable production load, then improve using your own comparable evidence.
